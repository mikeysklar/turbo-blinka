Reproduce

Every run prints a checksum that must match.

git clone https://github.com/mikeysklar/turbo-blinka && cd turbo-blinka
python3 bench/run_bench.py bench/src/pixels.py                  # before
python3 bench/run_bench.py --shim numba bench/src/pixels.py     # numba
python3 bench/displayio_refresh.py                              # stock refresh
(cd fastpath/cy && cythonize -i -3 fill_kernel.py)
python3 bench/displayio_refresh.py --fast cython                # fast path
